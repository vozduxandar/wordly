# Wordly

Wordly - Python және pygame-ce арқылы жасалған шағын сөз табу ойыны.
Ойында 5 әріптен тұратын ағылшын сөзін 6 мүмкіндікте табу керек.

## Қалай ойнайды?

Сөзді жазып, Enter басамыз. Әріптердің түсі жауаптың қаншалықты дұрыс екенін көрсетеді:

- Жасыл: әріп те, орны да дұрыс
- Сары: әріп сөзде бар, бірақ орны басқа
- Сұр: ондай әріп сөзде жоқ

Backspace әріпті өшіреді. Ойын біткен соң R басып, қайта бастауға болады.

## Кім не жасады?

- **Бексұлтан (`beksultan.py`)**: `WordRow` класын жасады. Ұяшықтарды және әріптерді экранға шығарады.
- **Әліби (`alibi.py`)**: `EditableRow` класын жасады. Әріп жазу, өшіру және жолдың толғанын тексеру осы жерде.
- **Қыран (`kyran.py`)**: `CheckedRow` класын жасады. Сөзді тексеріп, әріптердің түсін анықтайды.
- **`main.py`**: бәрін біріктіретін негізгі файл. Терезе, ойынның жүруі, жеңіс пен жеңіліс осы жерде басқарылады.

Екінші кезеңде кодты бөлек кластарға бөлдік. `EditableRow` және `CheckedRow` екеуі де `WordRow` класынан мұра алады.

## Іске қосу

Алдымен pygame-ce орнату керек:

```bash
pip install pygame-ce
```

Содан кейін ойын папкасында:

```bash
python main.py
```
