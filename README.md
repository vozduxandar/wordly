# Wordly

Wordly - Python және pygame-ce арқылы жасалған шағын сөз табу ойыны.
Әр деңгейде 5 әріптен тұратын ағылшын сөзін 6 мүмкіндікте табу керек.

## Қалай ойнайды?

Сөзді жазып, Enter басамыз. Әріптердің түсі жауаптың қаншалықты дұрыс екенін көрсетеді:

- Жасыл: әріп те, орны да дұрыс
- Сары: әріп сөзде бар, бірақ орны басқа
- Сұр: ондай әріп сөзде жоқ

Алдымен мәзір ашылады. Enter не «Ойынды бастау» батырмасы ойынды бастайды.

- A-Z: әріп жазу; Backspace: соңғы әріпті өшіру; Enter: бес әріпті тексеру.
- F1: қаріпті ауыстыру. Мәзірдегі «Қаріп» батырмасын тышқанмен де басуға болады. Таңдауға жүйеде бар әрі қазақ әріптерін көрсететін Segoe UI, Arial және Calibri ұсынылады.
- Мәзірдегі «Дыбыс: қосулы/өшірулі» батырмасы музыка мен әсер дыбыстарын бірге қосады немесе өшіреді. Батырманы тышқанмен, не Tab арқылы таңдап Enter/Space пернесімен басуға болады. Аудио құрылғысы болмаса, «Дыбыс жоқ» жазуы көрсетіледі.
- Tab және Shift+Tab: мәзір мен нәтиже экранындағы батырманы таңдау; Enter немесе Space: таңдалған әрекетті орындау. Батырмаларды тышқанмен де басуға болады.
- Esc: ойыннан мәзірге оралу; мәзірде Esc терезені жабады.
- Жеңістен кейін Enter немесе R келесі деңгейге өткізеді. Жаңа сөз бар сөздер жиынынан алынады, сол сөз бірден қайталанбайды. Жеңілістен кейін Enter немесе R сол деңгейді сол сөзбен қайта бастайды.
- Нәтиже экранында M мәзірді ашады. Жеңістен кейін мәзірге оралсаңыз, келесі деңгей сақталады; жеңілістен кейін сол деңгей қалады. Мәзірден бастау әрекеттерді тазалайды.

Әріптер тексерілгенде ұяшықтар кезекпен ашылады; деңгей біткенде қысқа әсер көрсетіледі.

## Кім не жасады?

- **Бексұлтан (`word_row.py`)**: `WordRow` класын жасады. Ұяшықтарды және әріптерді экранға шығарады.
- **Әліби (`editable_row.py`)**: `EditableRow` класын жасады. Әріп жазу, өшіру және жолдың толғанын тексеру осы жерде.
- **Қыран (`checked_row.py`)**: `CheckedRow` класын жасады. Сөзді тексеріп, әріптердің түсін анықтайды.
- **`main.py`**: экрандарды, деңгейлерді және қаріпті басқарады.
- **`menu_word.py`, `particle.py`, `sound.py`**: мәзірдегі әріп спрайты, қысқа визуалды әсер және дыбыстар.

Екінші кезеңде кодты бөлек кластарға бөлдік. `EditableRow` және `CheckedRow` екеуі де `WordRow` класынан мұра алады.

## Дыбыстар

`assets/catch.wav`, `assets/hit.wav`, `assets/over.wav` файлдары `C:\prj` ішіндегі `assets/star_0.png` файлы бар 17.11 күнгі оқу ZIP архивіндегі жұлдыз ойынынан алынды. Wordly-де олар тиісінше толық сөзді қабылдағанда, толық емес сөзді Enter арқылы жібергенде және алты әрекет таусылғанда ойналады. Дыбыс құрылғысы жоқ болса, ойын дыбыссыз жалғасады.

Фондық музыка үшін пайдаланушы қосқан `assets/music.m4a` файлы `assets/music.ogg` пішіміне көшіріліп түрлендірілді: pygame ойында OGG нұсқасын ойнатады, ал бастапқы M4A өзгеріссіз қалды. Музыка мәзір ашылғанда басталады және ойын мен мәзір арасында үзілмейді. Мәзірдегі дыбыс батырмасымен өшіргенде музыка мен әсерлер тоқтайды; қайта қосқанда музыка басынан ойналады. M4A метадерегінде шығарма `Wordle Theme Song`, орындаушы `Vista Sounds Official` деп көрсетілген; файлды жариялау құқығын бөлек тексеру керек.

## Іске қосу

Алдымен pygame-ce орнату керек:

```bash
pip install pygame-ce
```

Содан кейін ойын папкасында:

```bash
python main.py
```
